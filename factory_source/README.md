## What This Is

MYTHOS LOREPACK FACTORY is the standalone machinery used to create, manage, retrieve, export, and restore **LOREPACK** memory packages.

A LOREPACK is a portable representation of an AI entity's accumulated experience and continuity.

It is not the AI model.

It is not the persona itself.

It is not a chatbot.

It is the **portable memory substrate** that can be attached to an AI entity.

The Factory provides the machinery required to turn source material and conversational experience into structured, searchable, portable memory.
